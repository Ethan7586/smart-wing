# 智慧翼微信小程序

这是可以直接导入微信开发者工具的原生小程序工程，首版使用本地演示数据，不依赖网络和生产凭据。

## 直接预览

在微信开发者工具选择“导入项目”，目录选择本文件所在的 `apps/wechat-miniapp`。当前 `AppID` 为 `touristappid`，可直接游客模式编译。取得正式小程序 AppID 后，只替换 `project.config.json` 中的 `appid`。

## 当前进度

- 智慧翼统一 VI 和五栏导航：`首页 / 分类 / 会员码 / 订单 / 我的`
- 首页视觉结构与本地演示状态已实现，等待开发者工具真实截图验收
- 分类、会员码、订单和我的仅为阶段占位页，尚未实现业务
- 主视觉、商品图与卖场 Logo 尚无正式素材，页面明确显示占位
- 服务端接口尚未接入，所有演示数据均在页面顶部标明

## 安全边界

当前没有生成可用会员码，不能用于真实身份核验或支付。真实版本必须由智慧翼服务端签发短时、可撤销的会员码。小程序不得保存 AppSecret、微信支付私钥、短信密钥或合作商密钥。
