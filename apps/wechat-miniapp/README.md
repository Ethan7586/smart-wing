# 智慧翼微信小程序

这是可以直接导入微信开发者工具的原生小程序工程，首版使用本地演示数据，不依赖网络和生产凭据。

## 直接预览

在微信开发者工具选择“导入项目”，目录选择本文件所在的 `apps/wechat-miniapp`。当前 `AppID` 为 `touristappid`，可直接游客模式编译。取得正式小程序 AppID 后，只替换 `project.config.json` 中的 `appid`。

## 已实现

- 智慧翼统一 VI 和五栏导航：`首页 / 分类 / 翼码 / 订单 / 我的`
- 所有选品页右上角常驻购物车与数量角标
- 首页、分类、商品详情、购物车、动态翼码、订单、会员中心
- 本地购物车增减、角标同步、45 秒翼码轮换展示
- 手机未认证、企业资格、可买范围和组合支付提示

## 安全边界

当前二维码仅为视觉演示，不能用于真实身份核验或支付。真实版本必须由智慧翼服务端签发短时、可撤销的翼码。小程序不得保存 AppSecret、微信支付私钥、短信密钥或合作商密钥。
