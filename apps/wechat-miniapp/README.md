# 智慧翼微信小程序

这是可以直接导入微信开发者工具的原生小程序工程。首页会员资产仍使用明确标注的本地演示数据；分类结构与主 Shop 共用同一份机器可读契约，公开商品无需登录即可从同一生产数据库异步读取。

## 直接预览

在微信开发者工具选择“导入项目”，目录选择本文件所在的 `apps/wechat-miniapp`。Ethan 已确认正式小程序 AppID 为 `wx4df4137881a1d2bc`；开发者工具只需要 AppID，不需要 AppSecret。

## 当前进度

- 智慧翼统一 VI 和五栏导航：`首页 / 分类 / 会员码 / 订单 / 我的`
- 首页已通过 Ethan 的阶段验收
- 分类页已实现完整分类结构、独立滚动、异步状态与重试；访客可直接读取公开商品，登录后再识别会员价与可购资格
- 会员码、订单和我的仍为阶段占位页，尚未实现业务
- 主视觉、商品图与卖场 Logo 尚无正式素材，页面明确显示占位
- 小程序不得直连数据库；公开商品与会员商品都只能经 `commerce-api` 获取，登录不得成为浏览商品的前置条件

## 安全边界

当前没有生成可用会员码，不能用于真实身份核验或支付。真实版本必须由智慧翼服务端签发短时、可撤销的会员码。小程序不得保存 AppSecret、微信支付私钥、短信密钥或合作商密钥。
