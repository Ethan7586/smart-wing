## 标准组件与图标来源

1. 微信端组件行为与安全区：微信小程序官方规范。
2. 小程序标准组件补充：腾讯 `tdesign-miniprogram` / `tdesign-miniprogram-starter-retail`（MIT）。
3. React 参考图标：`lucide-react`，以两个参考项目中实际 import 的图标为准。
4. Android 参考图标：Material Symbols / Material Icons（Apache 2.0），以 Kotlin 源码中实际使用的 `Icons.Filled` / `Icons.Outlined` 为准。
5. 品牌图标仅使用 `packages/design-system/src/brand/`，不得由通用图标库代替。
