# 如何正确启动和验收

## 最简单的启动方法

双击小程序目录中的：

`00-双击启动微信小程序.cmd`

它会把正确的项目根目录（包含 `project.config.json` 的 `apps/wechat-miniapp`）交给微信开发者工具。不要直接打开 `miniprogram` 子目录，也不要打开仓库根目录。

如果启动窗口提示“服务端口已关闭”：

1. 在微信开发者工具中打开“设置”。
2. 进入“安全设置”。
3. 开启“服务端口”。
4. 关闭多余的微信开发者工具窗口，只保留一个实例。
5. 再次双击 `00-双击启动微信小程序.cmd`。

## 手工导入

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 目录必须选择 `apps/wechat-miniapp`。
4. 当前配置为 `touristappid`，只用于游客模式界面编译。
5. 点击工具栏“编译”。

如果工具提示正在使用 Canary/灰度基础库，请在“详情 → 本地设置”中改为一个正式稳定基础库后重新编译；不要用灰度基础库的工具内部报错判断业务代码好坏。

## 什么才叫启动成功

必须同时满足：

1. 模拟器显示首页内容，不是只有原生标题和白屏。
2. Build/Console 中没有 WXSS、WXML 或 JavaScript 编译错误。
3. 首页可以滚动，底部五栏能够显示。
4. 必须提交微信开发者工具真实截图，不能只报告“文件已写入”。

游客模式的 `webapi_getwxaasyncsecinfo:fail`、`operateWXData` 提示可能来自工具环境；只有在本地 WXSS/WXML/JS 编译为零错误且页面仍异常时，才单独排查它。不能把本地语法或路径错误归因于网络。

## 代码完成后的默认动作

Ethan 已授权：每个页面代码与门禁通过后，执行方无需再次询问，必须直接把正确工程送入微信开发者工具，并按以下顺序留下证据：

1. `open`：打开 `apps/wechat-miniapp`，不是仓库根目录或 `miniprogram` 子目录。
2. `compile`：确认模拟器出现本次页面，Console 无 WXML、WXSS、JavaScript 红字。
3. `preview`：正式 AppID、登录和域名条件具备时生成真机预览，并保存结果。
4. `upload`：预览通过后可上传微信后台“开发版本”，记录版本号、提交哈希、时间和返回结果。

这里的永久授权不包含“提交审核”“灰度发布”或“正式发布”；这些动作仍需 Ethan 单独确认。条件不具备时必须写清阻断，不能把 `open` 或游客模式编译说成正式上传成功。

## 本次白屏的真实原因

这次白屏不是 V2Ray 或网络造成的。已经修复的本地阻断项是：

1. `app.wxss` 曾跨出小程序根目录引用 Web 端 `tokens.css`，开发者工具无法找到该文件。
2. WXML 曾直接调用 Page JavaScript 函数格式化金额，小程序模板不支持这种写法。

后续任何任务不得恢复跨目录 CSS 引用，也不得在 WXML 中直接调用 Page 函数。

## 正式 AppID

开发者工具只需要 AppID，不需要 AppSecret。AppSecret 永远只能放在服务端密钥环境中，不得写入项目配置、小程序代码或 Git。
